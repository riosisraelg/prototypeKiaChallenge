2. **IoT Policy**: `kia-paintshop-prototype-policy`

4. **IoT Rule**: `kia_paintshop_prototype_ingest_rule`
   - Topic pattern: `kia/paintshop/+/+`
   - SQL: `SELECT topic(3) as area, topic(4) as variable_id, * FROM 'kia/paintshop/+/+' WHERE timestamp IS NOT NULL`
   - Action: Invoke Lambda function `kia-paintshop-prototype-ingest`
   - Error logging to CloudWatch

## Topic Structure

MQTT messages must follow this pattern:
```
kia/paintshop/{area}/{variable_id}
```

Where:
- `{area}`: One of `pre-treatment`, `e-coat`, or `production-control`
- `{variable_id}`: Unique variable identifier (e.g., `PT-TEMP-001`)

### Examples:
- `kia/paintshop/pre-treatment/PT-TEMP-001`
- `kia/paintshop/e-coat/ED-VOLTAGE-005`
- `kia/paintshop/production-control/PC-SPEED-012`

## Message Format

```json
{
  "variable_id": "PT-TEMP-001",
  "area": "pre-treatment",
  "timestamp": "2024-01-15T10:30:00.000Z",
  "value": 65.5,
  "unit": "°C",
  "quality": "good",
  "metadata": {
    "min_range": 60.0,
    "max_range": 70.0,
    "alarm_low": 62.0,
    "alarm_high": 68.0
  }
}
```

## Security Implementation

### 1. X.509 Certificate Authentication
- All MQTT connections require valid certificates
- Certificates generated by Terraform and saved locally
- Private keys have restricted permissions (0600)

### 2. Minimum Privilege Policy
- Devices can only publish to `kia/paintshop/*` topics
- No wildcard permissions
- Explicit resource ARNs in policy

### 3. TLS Encryption
- All connections use TLS 1.2+
- Port 8883 (MQTT over TLS)
- Amazon Root CA certificate validation

### 4. IAM Role Separation
- Dedicated IAM role for IoT Rule
- Minimum permissions (Lambda invoke + CloudWatch Logs)
- No cross-service access

## Known Limitations

1. **Lambda Dependency**: IoT Rule references Lambda function that doesn't exist yet
   - Will show errors in CloudWatch until Lambda is created (Task 6)
   - This is expected and will be resolved in next tasks

2. **Single Certificate**: Only one certificate generated
   - Sufficient for single simulator
   - Multiple simulators would need separate certificates

3. **No Certificate Rotation**: Certificates don't auto-rotate
   - For production, implement certificate rotation
   - For prototype, manual rotation is acceptable
